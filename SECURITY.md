# Security Policy / 安全政策

Project Wutong's Security, Sync and Federation profiles are **experimental** and have not
been independently audited. Do not rely on them for production confidentiality or integrity.

## Reporting a vulnerability

Please report privately via **GitHub Security Advisories** ("Report a vulnerability" on the
Security tab of this repository) or email **wutong-dev@mail.grokbot.com**. Do not open public
issues for vulnerabilities. We aim to acknowledge within 3 business days and to agree a
coordinated disclosure date (default 90 days).

请通过仓库 Security 页的“Report a vulnerability”或邮件私下报告漏洞，不要公开提交 Issue。
